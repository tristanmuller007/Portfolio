Vue d'ensembleOverview

Mettre en place, sur un Raspberry Pi sous Linux, tout ce qu'il faut pour développer et héberger une application web.Setting up everything needed to develop and host a web app on a Raspberry Pi running Linux.

ObjectifObjective

Comprendre ce qu'il y a sous un site web : le système, le serveur HTTP, le langage côté serveur, la base de données et la sauvegarde.Understand what sits underneath a website: the OS, the HTTP server, the server-side language, the database and backups.

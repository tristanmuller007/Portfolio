Vue d'ensembleOverview

Memorizz part d'un jeu simple, le memory, pour en faire une application graphique complète : plusieurs thèmes, plusieurs modes, un classement, des réglages et une interface soignée.Memorizz takes a simple game, memory, and turns it into a full graphical application: several themes, several modes, a leaderboard, settings and a polished interface.

ObjectifObjective

Concevoir une application en programmation orientée objet, gérer la navigation entre plusieurs écrans, manipuler des ressources (images, sons, fichiers) et enregistrer des données.Design an object-oriented application, handle navigation between screens, work with assets (images, sounds, files) and save data.

DémarcheApproach

  1. Environ 4 500 lignes de Processing réparties en classes.About 4,500 lines of Processing split into classes.
  2. Une classe Page qui gère la navigation entre les écrans.A Page class that handles navigation between screens.
  3. Des classes séparées pour le jeu, le mode Enfer, le classement et les réglages.Separate classes for the game, Hell mode, leaderboard and settings.
  4. Scores enregistrés dans un fichier texte et relus au lancement.Scores saved to a text file and read back on launch.

FonctionnalitésFeatures

  • Facile (16 cartes), Moyen (24) et Expert (36)Easy (16 cards), Medium (24) and Expert (36)
  • Thèmes : drapeaux, pays, hymnes, animaux, sports, nature...Themes: flags, countries, anthems, animals, sports, nature...
  • Mode Enfer : les cartes se mélangent toutes les 5 secondesHell mode: cards shuffle every 5 seconds
  • Classement avec saisie du nom du joueurLeaderboard with player name entry
  • Français / anglais, mode sombre, option d'accessibilitéFrench / English, dark mode, accessibility option

Ce que j'ai apprisWhat I learned

Beaucoup d'écrans, un seul point d'entréeMany screens, one entry point

Chaque écran est une classe, et la classe Page décide lequel afficher. Ajouter un écran ne touche pas aux autres.Each screen is a class and the Page class decides which one to show. Adding a screen doesn't touch the others.

Des cartes qui bougent pendant la partieCards that move during the game

En mode Enfer, les cartes changent de place toutes les 5 secondes sans perdre leur état retourné ou trouvé.In Hell mode, cards swap places every 5 seconds without losing their turned or matched state.

Vue d'ensembleOverview

Un « livre dont vous êtes le héros » est un récit où le lecteur avance de page en page selon ses choix. L'application permet de l'écrire, d'y jouer directement et de l'exporter en site web.A choose-your-own-adventure book is a story where the reader moves from page to page based on their choices. The app lets you write one, play it straight away and export it as a website.

ObjectifObjective

Développer une application de bureau complète en C++ avec Qt Widgets, avec un vrai modèle objet (livre, pages, choix, conditions, état du joueur) et une sauvegarde persistante.Build a complete desktop app in C++ with Qt Widgets, with a proper object model (book, pages, choices, conditions, player state) and persistent saves.

DémarcheApproach

  1. Modélisation objet : Livre, Page, Choix, Condition, EtatJoueur.Object model: Book, Page, Choice, Condition, PlayerState.
  2. Interface à onglets : Édition, Lecture, Paramètres.Tabbed interface: Edit, Play, Settings.
  3. Sérialisation du livre en JSON pour l'enregistrer et le rouvrir.Book serialised to JSON to save and reopen it.
  4. Génération d'un site web complet à partir du livre.Full website generated from the book.
  5. Travail en équipe avec Git sur le GitLab de l'IUT.Team work with Git on the university's GitLab.

FonctionnalitésFeatures

  • Éditeur de texte riche : gras, italique, police, couleur, images, listes, liensRich-text editor: bold, italics, fonts, colours, images, lists, links
  • Liens entre pages qui portent des effets, par exemple -10 PV ou un objet gagnéLinks between pages that carry effects, for example -10 HP or an item gained
  • Choix sous condition : objet possédé ou page déjà visitéeConditional choices: item owned or page already visited
  • Vérification de la cohérence : pages inaccessibles, liens cassésConsistency check: unreachable pages, broken links
  • Mode lecture avec points de vie, expérience, inventaire et détection des finsPlay mode with health, experience, inventory and ending detection
  • Export d'un site web avec carte interactive Leaflet, export PDFWebsite export with an interactive Leaflet map, PDF export

Garder l'état du joueur sur le site exportéKeeping player state on the exported site

Chaque page du livre devient une page HTML séparée. Les points de vie et l'inventaire sont conservés d'une page à l'autre avec le localStorage du navigateur.Each book page becomes a separate HTML page. Health and inventory carry over from page to page through the browser's localStorage.

Des effets portés par les liensEffects carried by links

Un lien comme page3.html#pv=-10;objet=Epee est analysé à l'ouverture de la page pour appliquer ses effets.A link such as page3.html#pv=-10;objet=Epee is parsed when the page opens to apply its effects.
